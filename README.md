# CodeAlpha Calculator

## Overview
This project is a simple web-based calculator application. It allows users to perform basic arithmetic operations with a user-friendly interface.

## Features
- Addition, subtraction, multiplication, and division
- Responsive and clean design
- Easy to use

## Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Edge, etc.)

### Usage
1. Clone the repository:
   ```
   git clone https://github.com/AbiramiR-27/CodeAplha_Calculator.git
   ```
2. Open `task2.html` in your web browser to use the calculator.

## Project Structure
```
CodeAplha_Calculator/
  task2.html
```

## Customization
- To modify the calculator's appearance or functionality, edit the `task2.html` file.
